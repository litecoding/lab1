# Ключова Майстерня — веб-сайт

Веб-сайт для майстерні з виготовлення ключів. HTML/CSS верстка.

## Структура сайту

| Сторінка | Опис |
|----------|------|
| `index.html` | Головна — hero-блок, переваги, заклик до реєстрації |
| `services.html` | Послуги — список послуг з кнопкою «Замовити» при наведенні |
| `about.html` | Про нас — історія, переваги, місія |
| `contacts.html` | Контакти — адреса, телефон, email, інтерактивна карта |
| `registration.html` | Реєстрація — форма з валідацією |

## Файли проекту

- `index.html` — головна сторінка
- `services.html` — сторінка послуг
- `about.html` — сторінка «Про нас»
- `contacts.html` — сторінка контактів
- `registration.html` — сторінка реєстрації
- `styles.css` — стилі всього сайту
- `script.js` — валідація форми реєстрації

## Функціонал

### HTML
- Семантична розмітка
- Єдина навігація на всіх сторінках
- Форма реєстрації з `label`, `placeholder`, `novalidate`
- Вбудована карта OpenStreetMap на сторінці контактів

### CSS
- Адаптивна верстка (мобільні, планшети, десктоп)
- Кнопка «Замовити» з’являється при наведенні на послугу
- Плавні переходи та hover-ефекти
- CSS-змінні для кольорів та відступів

### JavaScript
- Валідація форми реєстрації (заповненість, формат email)
- Повідомлення про помилки під полями
- Очищення помилок при введенні
- При успішній валідації — alert та скидання форми
