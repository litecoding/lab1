# Веб-сайт з формою реєстрації


### 1. HTML-структура
- Поля для введення: ім'я, прізвище, електронна пошта, пароль
- Семантична розмітка з `label` та `placeholder`
- Атрибут `novalidate` для керування валідацією через JavaScript

### 2. CSS-стилізація
- Стилізовані текстові поля з ефектом фокусу та плавними переходами
- Кнопка «Відправити» з hover-ефектом
- Оформлений заголовок та підзаголовок сторінки
- Підсвітка помилок (червона рамка для невалідних полів)
- Градієнтний фон

### 3. JavaScript-валідація
- Перевірка заповненості всіх полів перед відправленням
- Додаткова перевірка формату електронної пошти
- Відображення повідомлень про помилки під кожним полем
- Очищення помилок при введенні даних
- При успішній валідації — показ повідомлення та скидання форми

### 4. Респонсивність
- Адаптація для мобільних пристроїв (медіа-запит `max-width: 480px`)
- Зменшені відступи та розміри шрифтів на малих екранах
- Мета-тег `viewport` для коректного масштабування

## Структура проекту

- `index.html` — головна сторінка з формою реєстрації
- `styles.css` — стилі форми та сторінки
- `script.js` — валідація полів форми
